# Figures

`architecture.excalidraw` is generated by `generate.py`, and
`architecture.png` is the render used by the README.

The scene makes one claim: `kv_server` reaches disk through the LSM engine and
one of four I/O backends. The Raft panel marks the optional `--raft-id` write
path and its leader-only behavior.

Regenerate the scene from the repository root:

```bash
python3 -B docs/figures/generate.py
```

Render it with the Excalidraw CLI. The CLI needs Chrome, Chromium, Edge, or
Firefox. Set `EXCALIDRAW_BROWSER_PATH` when the browser is not on the default
path:

```bash
EXCALIDRAW_BROWSER_PATH=/path/to/chrome \
  excalidraw render docs/figures/architecture.excalidraw \
  --out docs/figures/architecture.png \
  --scale 2 --max-width 3200 --max-height 2000
```

Check the PNG after every edit:

- The figure makes one claim.
- Every label fits inside its box.
- Every arrow has a label.
- No arrow crosses text.
- The smallest text is readable at page width.
- The scene and the PNG are both current.

The palette comes from `agents/excalidraw.nix` in the personal nixos
repository. Strokes carry the role and the fills stay pale.
